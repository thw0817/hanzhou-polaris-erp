# 合规必填项与 1630/1631 回读修复

日期：2026-08-26

## 变更

- 单 SKC 合规详情只展示 SHEIN 合规要求回读中 `required=true` 的项目；本地兜底不再把非必填的证书、代理、警示语或实拍图槽位显示出来。
- 1630/1631 只接受 SHEIN `reportDecision.reportType` 回读结果，不使用前端属性推断。详情页始终显示“官方报告类型”：已返回时显示 1630 或 1631，未返回时显示等待状态。
- 官方报告类型已返回时，即使其他合规摘要没有阻断，仍渲染合规编辑器，并只保留与官方类型匹配的按 SKC 报告上传规则。
- 合规工作台列表增加“官方报告”列；未返回官方类型时显示“等待 SHEIN 返回”。

## 安全边界

- 本次没有新增 SHEIN 写接口调用，也没有改变报告上传/绑定的服务端门禁。
- 上传仍需有效的 SHEIN 合规规则快照；前端只负责呈现与暂存，真实提交继续由现有服务端契约完成。
- 所有查询沿用当前租户、店铺和用户权限隔离，不使用跨店铺缓存。
