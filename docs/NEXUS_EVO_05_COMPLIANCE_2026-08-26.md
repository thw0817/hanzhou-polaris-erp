# NEXUS-EVO-05：合规官方必填视图与 1630/1631 闭环

日期：2026-08-26

## 目标

- 单个 SKC 合规详情只展示 SHEIN 当前回读为必填的字段与实拍图分组。
- 1630/1631 类型以 SHEIN 官方回读为唯一判定来源。
- 在官方类型尚未返回时，页面仍保留清晰的等待区块；返回后在同一位置展示对应报告上传入口。
- 恢复单个 SKC 主图缩略图，避免用户进入详情后失去商品识别上下文。

## 本轮改动

- `ComplianceDetailPage` 在详情标题旁恢复主图缩略图；无图时展示明确占位，不发起额外图片请求。
- 官方报告区块在详情数据存在时始终展示：未返回类型显示“等待 SHEIN 返回”，返回类型后显示 1630/1631 与下一步上传提示，歧义时展示官方阻断原因。
- 保留 `ComplianceDraftEditor` 的官方必填过滤和每个 SKC 的报告绑定逻辑，不引入本地 1630/1631 推断。
- 新增 UI 回归合同，锁定官方报告等待态和主图缩略图。

## 验证

- 合规详情与工作台 UI 专项：`22/22` 通过。
- 服务端全量测试、V2 构建和发布审计需在本阶段汇总门禁时再次执行。

## 边界

本阶段未改变 SHEIN 写接口、发布状态机、权限作用域或云端配置，未部署云端；云端发布统一留到 NEXUS-EVO-10。
