# NEXUS-EVO-08：销量库存、在途与经营分析口径验收

日期：2026-08-26

## 验收范围

本阶段对总览、销量与库存、经营预警和经营数据刷新链路进行只读验收，重点检查 SHEIN API 口径、缓存降级和多店铺并发下是否会误判。

## 结论

- 销量来自 `/open-api/goods/query-sku-sales` 的官方字段：实时、昨日、7 日和 30 日按 SKU 回读后聚合到 SKC。
- 实际库存与在途库存来自 `/open-api/stock/stock-query`，分别保留可用库存、锁定库存和 `totalTransitQuantity`；字段缺失显示未知，不把未知写成 0。
- 平台上下架状态只接受 `/open-api/goods-compliance/skc-label-list` 的精确回读；旧快照或本地推断会降级为“待同步”。
- SKC 展开后逐 SKU 展示销量、实际库存、在途库存、可售天数和建议备货，建议备货明确属于本地分析值，不覆盖 SHEIN 原始字段。
- 刷新通过店铺级持久化快照、单店铺任务锁、手动刷新冷却和队列 Worker 完成；页面进入不会自动触发 SHEIN 请求，默认调度关闭。
- 缓存过期、SHEIN 限流、可选接口失败和重新授权均保留可操作状态，不把服务异常误判成商品失败。

## 回归验证

- 经营服务、刷新 Worker、调度器、概览 UI 和 SHEIN 读接口专项：`61/61` 通过。
- 验证覆盖：租户/店铺授权、并发刷新去重、持久化快照、限流退避、实际/在途库存、SKU 缺失字段、平台状态降级、库存风险和总览周期聚合。

本阶段未引入新的分析推算或 SHEIN 写接口；全量测试、构建、发布审计统一在 NEXUS-EVO-10 门禁执行。
