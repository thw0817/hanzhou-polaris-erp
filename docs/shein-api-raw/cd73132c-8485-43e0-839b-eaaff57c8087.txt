查询分类可用属性
POST
/open-api/goods/query-attribute-template
自运营
全托管
半托管
支持查询店铺可用属性。平台内不同店铺在各个类目下可用的属性不同，因此建议按店铺维度更新数据。同时因平台规则可能会变更，如增加销售属性，修改属性是否必填等，建议一周更新一次。

属性包括：商品属性、主销售属性（skc）、次销售属性（sku）、尺码表属性，属性规则复杂，可查看SHEIN商品属性介绍了解详细对接方式。

attribute_infos
object[]	否	
某个product_type下属性列表。

建议查看SHEIN商品属性介绍了解更多对接细节。

attribute_id
long	否	
属性id

attribute_name
string	否	
属性id的名称。常见的销售属性有颜色、尺码；常见的商品属性有产品特征、产品功能、是否需要电源等

attribute_is_show
int64	否	
属性是否会在消费者端显示；1-展示，2-不展示

attribute_type
int64	否	
属性类型。决定属性在商品发布接口中哪个字段内入参。

1-销售属性（在skc_list和sku_list入参）；2-尺寸属性（在size_attribute_list传参），3-成分属性（需要同时结合data_dimension的值，判断在发品接口的入参字段），4-普通属性（需要同时结合data_dimension的值，判断在发品接口的入参字段）

attribute_label
int64	否	
主销售属性（SKC属性标签）。只有主销售属性才可在skc_list中传参。

1-代表是主销售属性，主销售属性也可用于次销售属性; 0: 不是主销售属性。

attribute_mode
int64	否	
属性值的录入方式。

0 - 手工输入属性值，常见于尺寸属性，只可输入正整数，需在attribute_extra_value中入参；

1-下拉多选，即属性下可以有多个属性值，需在attribute_value_id中入参；

2-销售属性专用，下拉单选，需在attribute_value_id中入参；

3-下拉单选，需在attribute_value_id中入参

4-下拉多选+手工输入参数，需在attribute_value_id和attribute_extra_value中入参

attribute_input_num
integer	否	
属性值个数限制。

当attribute_mode=1时，最多可选的属性值个数，0代表无限制。

attribute_status
int64	否	
属性是否必填。 1-不可填写（属性可能已废弃）；2-选填；3-必填。必填属性如果不填，则会报错；

attribute_remark_list
integer[]	否	
属性标识。说明属性归属于什么场景。1:重要,2:合规,3:质量,4:关务

data_dimension
integer	否	
商品属性的绑定维度（attribute_type=3/4）。

1-skc维度，在发品接口的product_attribute_list中入参

3-sku维度，在发品接口的sku_scope_attribute_list中入参



attribute_value_info_list
object[]	否	
属性值列表

attribute_value
string	否	
属性值的具体内容

attribute_value_id
long	否	
属性值id

is_show
int64	否	
是否展示

is_custom_attribute_value
boolean	否	
是否为自定义属性值。true代表是，false代表否

rule_info_list
object[]	否	
当attribute_mode=3/4，支持手动输入值时（即发品接口中的product_attribute_list-attribute_extra_value），需要关注。此字段中给出了手动输入值的填写规则。

condition_operator
integer	否	
条件运算符(目前只作用于正整数、自然数的位数控制)； 0、空：表示不做控制，1：大于{value}位，2：小于{value}位

condition_type
integer	否	
校验规则类型。

1-值必须是正整数

2-值必须是连接符，可填符号的详见value

3-值允许输入小数，小数最多支持的位数见value

4-值必须是自然数 (0+正整数)

5-允许输入数字和连接符，数字最多允许2位小数，可填写的连接符见value，多个时逗号分隔，如-,~,/

id
int64	否	
校验规则id

value
string	否	
变量值。不同condition_type时代表意义不同，详细说明见condition_type

supplier_id
long	否	
商家id（如果值大于0，则表示是自定义属性）

main_attribute_status
long	否	
类目下主销售属性填写要求。注意：API发品时不论哪种情况，skc的主销售属性必须入参，只是不同填写要求主销售属性可用值不同。

1-不填：主销售属性必须使用【默认】属性。

2-选填：主销售属性可使用【默认】或其他属性。

3-必填：主销售属性不可以使用【默认】属性，只能用其他属性。

product_type_id
long	否	
商品类型id

meta
object	否	
count
integer	否	
customObj
object	否	


msg
string	否	
Error description, success: OK
traceId
string	否	
请求的唯一标识；用于异常报错跟踪

A：
