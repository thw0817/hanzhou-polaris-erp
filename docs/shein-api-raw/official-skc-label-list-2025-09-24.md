# 查询 SKC 的实拍图要求

来源：用户于 2026-08-21 提供的官方接口页附件。官方页面更新时间：2025-09-24 19:40:32。

- 方法：`POST`
- 路径：`/open-api/goods-compliance/skc-label-list`
- 限流：单开发者 20 次/秒
- 请求：`pageSize`（最多 100）、`pageNum`、`skcList`；可选 `skcShelfStatusList`、`reviewStatusList`、`isRequired`
- 出参分组：`labelGroup="1"` 为商品本体，`labelGroup="2"` 为外包装/包装
- 出参审核状态：`0` 待提交、`1` 审核中（后台可展示为通过）、`2` 通过、`3` 不通过
- 失败原因：`failReason`；顶层保留 `traceId`

查询入参和出参的审核状态枚举不同：入参 `1` 对应出参 `0`，入参 `2` 对应出参 `1/2`，入参 `3` 对应出参 `3`。

该接口返回要求、状态和失败原因，不包含历史图片 URL、原图或可删除图片 ID。内包装、外包装是本地素材槽位，提交时都归入官方包装数组，不能建成两个未经文档证明的官方分组。
