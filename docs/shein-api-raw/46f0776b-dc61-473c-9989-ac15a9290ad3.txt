查询商品建议零售价
POST
/open-api/goods-recommend-retail-price/search
自运营
全托管
半托管
查询商品当前的建议零售价详情。

注意：更新建议零售价前，请一定要查询商品当前建议零售价信息，因为更新是全量覆盖逻辑，提交时必须提供所有想要的信息，原数据会清空，以最新更新信息为准。

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
x-lt-signature
int64	是	
接口签名

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId

x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000

language
string	否	
响应msg的语种。不传时默认为英语，枚举值支持语种:英语:US 法语:FR 西班牙语:ES 德语:DE 中文简体:CN 泰语:TH 巴西葡语:PT 土耳其语：TR

请求参数（请求体）
收起
参数名称	数据类型	是否必须	描述
skc_name_list
string[]	是	
SKC平台编码列表，单次最多支持查询100个SKC。

返回参数（响应体）
收起
数据类型	是否必须	描述
code
string	是	
响应编码 成功：0

msg
string	否	
错误描述,成功：OK
info
object	否	
响应信息

skc_rrp_list
object[]	否	
SKC列表

skc_name
string	否	
SKC平台编码

status
integer	否	
SKC的建议零售价状态。1-审核中 2-包含抽检失败 3-包含审核失败 4-生效中 5-即将过期 6-已过期失效 7-部分过期失效。

其中2、3、7指的是SKC下的部分SKU有对应的状态，失败的部分代表没有建议零售价，具体是哪些SKU失败，可以查询审核记录：/open-api/goods-recommend-retail-price-audit/search

status_desc
string	否	
当前状态的说明文案。例如status=1，desc=当前skc内有sku的建议零售价正在审核中，不能进行修改

start_effective_time
int64	否	
SKC整体建议零售价的有效期开始时间(毫秒时间戳)

end_effective_time
int64	否	
SKC整体建议零售价的有效期结束时间(毫秒时间戳)

last_update_time
int64	否	
SKC整体建议零售价的最新更新时间(毫秒时间戳)

sku_rrp_info_list
object[]	否	
SKC下详细的SKU建议零售价信息列表

sku_code
string	是	
SKU平台编码

site_rrp_info_list
object[]	否	
站点维度建议零售价列表。一个SKU可能有多组数据。如果A站点是按站点维度提供的，则site有值，例如shein-fr；如果BCD三个站点是不按站点维度提供的，则site无值。

site
string	否	
站点。若例如shein-fr。如果站点为空，则代表此组数据为不分站点的SKU维度建议零售价。

currency
string	否	
币种。例如EUR

suggested_retail_price
string	否	
建议零售价

end_effective_time
int64	否	
结束生效时间(毫秒时间戳)

start_effective_time
int64	否	
开始生效时间(毫秒时间戳)。

type_one_proof
object	否	
类型一证明材料信息

attachments
string[]	否	
证明材料附件列表

proof_link
string	否	
证明链接
type_two_proof
object	否	
类型二证明材料信息

attachments
string[]	否	
证明材料附件列表
proof_link
string	否	
证明链接

traceId
string	否	
追踪码
