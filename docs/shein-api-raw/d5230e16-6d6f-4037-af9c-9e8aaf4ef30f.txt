获取全量环保耗材信息
GET
/open-api/goods-quality/environmental-label-rule/material-quality-tree-v2
自运营
全托管
半托管
商品若要打印环保标，需先通过此接口获取平台支持的环保材料信息。

环保材料信息共有两层，材料类型 -> 具体材料。

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
application/json

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId
x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000
x-lt-signature
string	是	
接口签名。

language
string	是	
支持返回的多语言报错信息，例如：language:en。默认返回中文多语言信息 英语:en 法语: fr 西班牙语:es 德语:de 中文简体:zh-cn 泰语:th 巴西葡语:pt-br

收起
数据类型	是否必须	描述

string	否

string	否	
info
object[]	是

integer	否	
环保材料类型ID

packageTypeName
string	否

isEnabled

环保材料类型是否可用

packageMaterials
object[]	是

packageMaterialId
integer	否

packageMaterialName

isEnabled
integer	否
