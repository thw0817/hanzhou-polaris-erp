打印合规标签
POST
/open-api/goods-compliance/label-print
自运营
全托管
SHEIN自营
半托管
POP
此接口支持打印商品相关的标签，标签中会包含多种信息，包括：环保标、GPSR、制造商、商品条码。

打印标签前，请先通过接口/open-api/goods-compliance/get-label-template查询每个SKC可用的标签模板，每个模板中包含不同信息，每个信息需提供的入参不同。

不同标签类型的图片示例参考文档。商家后台的标签打印流程可参考文档。

请求参数（请求体）
收起
数据类型	是否必须	描述
labelDetailList
object[]	否	
打印规则列表。即提供具体要打印什么内容的标签。单次最多支持10组规则，过多容易响应超时。

打印标签前，请先通过接口/open-api/goods-compliance/get-label-template查询每个SKC可用的标签模板，每个模板中包含不同信息，每个信息需提供的入参不同。

labelType
integer	是	
标签类型。各类型打印示例查看文档底部FAQ。

1-环保标：通常包含环保信息

2-GPSR标：通常包含GPSR信息（可能也会有环保标、商品条码、制造商信息）

3-商家自定义：包含内容不定，此类标签由商家在后台自行创建。具体包含信息可查询/open-api/goods-compliance/get-label-template。

4-GPSR+环保标：通常包含GPSR、环保信息。

5-商品条码合并标：通常包含商品条码（可能也会有环保标、商品条码、制造商信息）

labelCode
string	否	
打印的标签模板编码。通过/open-api/goods-compliance/get-label-template查询获取

非必填，不传值时系统会根据入参的skc和labelType去匹配出skc可打印的所有标签模板进行打印。

printNumber
integer	否	
标签打印数量。

非必填，只有在入参labelCode的情况下，printNumer才会生效。不传值时默认每个标签打印1份。

packageTypeId
int64	否	
此字段后续会废弃，请改用packageMaterialList入参（支持在一个标签内打印多个环保材料）。



packageMaterialId
int64	否	
此字段后续会废弃，请改用packageMaterialList入参（支持在一个标签内打印多个环保材料）。



packageMaterialList
object[]	否	
环保材料列表。支持一个标签内打印多个环保材料，最多10个材料。

标签内包含环保信息时，需要入参此列表。通常labelType=1/2/4/5时均可入参此信息，但最终打印结果中是否会有环保材料信息，取决于标签模板中是否有环保材料的变量信息。

packageTypeId
int64	否	
环保材料类型ID。可通过接口获取全量环保耗材信息（新）获取。

通常labelType=1/2/4/5时均可入参，但最终打印结果中是否会有环保材料信息，取决于标签模板中是否有环保材料的变量信息。

packageMaterialId
int64	否	
环保材料ID。可通过接口获取全量环保耗材信息（新）获取。

通常labelType=1/2/4/5时均可入参，但最终打印结果中是否会有环保材料信息，取决于标签模板中是否有环保材料的变量信息。

skc
string	是	
平台生成的SKC唯一编码。

必填，不论什么类型的标签都需要提供。

skuCode
string	否	
商品条码中显示的sku。标签内包含条码信息时，skucode和suppliersku选择一个入参即可，

通常labelType=2/4/5时均可入参，但最终打印结果中是否会有商品条码信息，取决于标签模板中是否有商品条码的变量信息。

supplierSku
string	否	
商品条码中显示的sku。标签内包含条码信息时，skucode和suppliersku选择一个入参即可，

通常labelType=2/4/5时均可入参，但最终打印结果中是否会有商品条码信息，取决于标签模板中是否有商品条码的变量信息。

orderNo
string	否	
商品条码中显示的采购单号。标签内包含条码信息时使用，非必填，不传值则单号位置显示空。

通常labelType=2/4/5时均可入参，但最终打印结果中是否会有商品条码信息，取决于标签模板中是否有商品条码的变量信息。

originCountry
string	否	
原产地。标签内包含GPSR信息时使用，由商家自定义输入值，填写国家名称。

通常labelType=2/4/5是均可入参。

productBatchNo
string	否	
产品批次号。标签内包含GPSR信息时使用，由商家自定义输入值。

通常labelType=2/4/5是均可入参。

warning
string	否	
警示语。标签内包含GPSR信息时使用，由商家自定义输入值。

通常labelType=2/4/5是均可入参。

uid
string	是	
打印规则的定位ID。每一行的定位ID不可重复。由开发者自定义输入，用于在返回中判断哪条规则打印失败，哪条打印成功。
