处理议价单
POST
/open-api/goods/discuss/process-discuss
全托管
半托管
只有议价单状态discussStatus=1（待商家确认）的议价单，才可以使用此接口调用处理。

议价单的处理操作有3项。

1、同意平台建议价：同意后，商品价格会变更为平台建议价格，议价单结束。

2、拒绝，放弃上架商品：拒绝后，议价单结束，商家无法再发起报价处理，商品无法上架

3、重新报价：商家对平台建议价有疑问，再次进行价格沟通。
