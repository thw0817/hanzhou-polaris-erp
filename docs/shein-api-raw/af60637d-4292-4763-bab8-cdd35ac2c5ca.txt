查询SKC的警告语绑定状态
POST
/open-api/goods-compliance/query-skc-warning-status
自运营
全托管
半托管
POP
查询SKC的警告语证书绑定要求和状态，（此接口已有新接口承接，建议优先对接新接口：/open-api/goods-compliance-requirements/list）。

警告语接口完整调用方案，详见文档。

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	否	
application/json

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId

x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000

x-lt-signature
string	是	
接口签名

language
string	否	
响应msg的语种。  不传时默认为英语，枚举值支持语种:英语:US 法语:FR 西班牙语:ES 德语:DE 中文简体:CN 泰语:TH 巴西葡语:PT 土耳其语：TR

请求参数（请求体）
收起
参数名称	数据类型	是否必须	描述
certificateTypeCodes
string[]	是	
证书类型编码列表，最多20个（目前警告语证书少于20个）。

建议先查询/open-api/goods-compliance/query-warning-certificate-rules，获取到全量的警告语证书code，将他们入参至此以确保查出的结果全是警告语的绑定数据。目前平台没有警告语证书标识，只能通过具体的certificateTypeCode来识别哪些是警告语。

pageNum
integer	是	
页数

pageSize
integer	是	
每页数量，最多200个

reviewStates
integer[]	否	
审核状态。0=没有提交过审核;1=待审核;2=审核成功;3=审核驳回

skcNames
string[]	否	
SKC平台编码，最多200个
