查询警告语证书的填写规则
POST
/open-api/goods-compliance/query-warning-certificate-rules
自运营
全托管
半托管
POP
此接口可获取所有需商家手动操作的警告语证书填写规则。详细信息可参考解决方案。

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	否	
application/json

x-lt-openKeyId
string	否	
访问用户隐私数据时的唯一权限标识 openKeyId

x-lt-timestamp
string	否	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000

x-lt-signature
string	否	
接口签名

language
string	否	
响应msg的语种。不传时默认为英语，枚举值支持语种:英语:US 法语:FR 西班牙语:ES 德语:DE 中文简体:CN 泰语:TH 巴西葡语:PT 土耳其语：TR

返回参数（响应体）
收起
数据类型	是否必须	描述
code
string	否	
响应码。

msg
string	否	
响应信息。

info
object[]	否	
具体信息。

规则数据的使用方式，请查看解决方案

certificateTypeId
int64	否	
证书类型ID

certificateTypeCode
string	否	
证书类型Code，唯一编码。后续查询、更新SKC警告语时均会使用。



certificateTypeName
string	否	
证书类型名称
presetInfo
object	否	
证书字段信息

isEnabled
integer	否	
字段信息是否启用。0-禁用；1-启用

presetFields
object[]	是	
字段详情

fieldCode
string	否	
字段Code，唯一编码。

fieldName
string	否	
字段名称，支持返回多语言。

fieldType
integer	否	
字段值的输入方式。

0=多选;1=单选;2=手动输入（实际上还是多选）

fieldSort
integer	否	
字段排序。

重要：排序值最大的字段是警告语字段，其他的均为常规字段。警告语字段、常规字段的处理逻辑不同。

isEnabled
integer	否	
字段是否启用。0-禁用；1-启用

presetFieldValues
object[]	是	
字段值信息

fieldValueId
int64	否	
字段值ID，唯一编码。

fieldValue
string	否	
字段值名称，支持返回多语言。

exclusionFieldValueIds
int64[]	否	
常规字段专用，互斥的字段值列表。

若常规字段值A下有互斥值B、C，则当商家选A时，BC均不能选。

mappingPaths
object[]	否	
警告语字段专用，警告语组装规则

fieldValueIds
int64[]	否	
警告语关联的常规字段值fieldValueId列表。

若警告语值a关联了常规字段值A、B，则当商家在常规字段中选了A或B中的任意值时，警告语字段中都需要传入a。

valueSort
integer	否	
字段值排序

isEnabled
integer	否	
字段值是否启用。0-禁用；1-启用

traceId
string	否	
追踪码
