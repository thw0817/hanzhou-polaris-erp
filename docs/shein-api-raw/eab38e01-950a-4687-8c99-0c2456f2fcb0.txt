店铺查商品末级分类
POST
/open-api/goods/query-category-tree
自运营
全托管
半托管
POP
该API支持查询店铺的商品末级分类信息，不同店铺，分类会有差异。

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
language
string	是	
默认返回中文多语言信息，支持语种：英语:en 法语: fr 西班牙语:es 德语:de 中文简体:zh-cn 泰语:th 巴西葡语:pt-br

Content-Type
string	是	
x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId
x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000
x-lt-signature
string	是	
接口签名

FAQ
Q：category_id和product_type_id的区别？
2025-05-26
A：
category_id用于告知平台商品属于哪个类目；product_type_id用于确认商品需要使用哪些商品属性和销售属性。category_id和product_type_id可以通过店铺可用接口获取：/open-api/goods/query-category-tree。
查看详情
Q：是否可以获得所有 SHEIN 类目？
2025-05-26
A：
不可以，暂时不支持提供 SHEIN 所有类目的接口，并且每个店铺只能传店铺可用类目，否则接口将报错。
Q：发布商品发现类目和属性报错
2024-12-24
A：
1、由于平台的可用属性和类目会随着业务发展而变更，建议实时查或者每隔一段时间更新店铺可用类目和可用属性的接口店铺可用属性： https://open.sheincorp.com/en/documents/apidoc/detail/3000429-1000001 店铺可用类目： https://open.sheincorp.com/en/documents/apidoc/detail/3000436-1000001 2、不要上传不是这个店铺可用的类目3、不要上传不是这个店铺可用的属性，如果发现属性从非必填变成必填，调用接口更新；
