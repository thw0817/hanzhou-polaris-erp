查询建议零售价审核记录
POST
/open-api/goods-recommend-retail-price-audit/search
自运营
全托管
半托管
建议零售价的审核记录明细。



请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
x-lt-signature
int64	是	
接口签名

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId

x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000

language
string	否	
响应msg的语种。不传时默认为英语，枚举值支持语种:英语:US 法语:FR 西班牙语:ES 德语:DE 中文简体:CN 泰语:TH 巴西葡语:PT 土耳其语：TR

请求参数（请求体）
收起
参数名称	数据类型	是否必须	描述
audit_state_list
integer[]	否	
审核状态列表。1: 待审核 2: 审核成功 3: 审核失败 5: 部分通过 6: 已撤回

5: 部分通过，说明SKC下有部分SKU已审核通过，获得有效期。

page_num
integer	是	
页码

page_size
integer	是	
每页大小，单页最大100

skc
string	否	
SKC平台编码

spu
string	否	
SPU平台编码

string	否

meta
object	否	
元数据
count
integer	否	
数据记录数

object	否

msg
string	否	
错误描述,成功：OK
traceId
string	否	
追踪码
