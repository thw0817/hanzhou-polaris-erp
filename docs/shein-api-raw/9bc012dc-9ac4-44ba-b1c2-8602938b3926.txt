Q：调用接口返回“子系统登录重定向”错误是什么原因？
2025-10-13
A：
该错误是由于接口调用的域名错误引起的。接口调用的域名与授权域名不一致会导致此错误。正式环境下，接口调用的正确域名应为：https://openapi.sheincorp.com 或 https://openapi.sheincorp.cn。 如果开发者错误地使用授权域名（例如：https://openapi-sem.sheincorp.com/#/empower）来调用接口，则会出现此报错。 以下是报错示例：{
	"code": "20302",
	"msg": "子系统登录重定向",
	"info": null,
	"bbl": null
}

Q：签名不正确的问题是什么原因？
2026-01-08
A：

常见的签名错误如下：1、getbytoken接口比较特殊，由于调用getbytoken接口时，开发者还没有openkey和secretKey，请使用后台应用的APP_ID和APP_Secretkey生成签名；2、一般签名错误出现的原因有以下几种：a、接口调用域名不正确；生产环境的密钥用了测试环境的域名会导致签名不正确b、请求头参数不正确；比如调用订单接口时，请求头是openKeyId等入参c、商家重置了密钥，导致开发者使用旧的密钥生成签名，建议查看应用后台的授权记录，以确认商家是否重新授权；d、Secretkey没有解密；3、通过getbytoken获取的密钥没有解密直接使用生成签名，会导致签名不正确，签名的生成方法可以查看文档： https://open.sheincorp.com/documents/system/passwdrule

正确的签名生成流程：1、签名概述在SHEIN开放平台中，每次接口调用都需要进行签名验证，以确保请求的合法性和安全性。本文档详细说明如何生成符合SHEIN平台要求的API签名。2、签名生成步骤步骤1：准备签名参数以获取采购单信息接口(/open-api/order/purchase-order-info)为例，签名需要准备以下参数：参数名称说明示例值OpenKeyId授权返回的OpenKeyIdB96C15416C9240DF96BAA0BC9B367C6DSecretKey授权返回的解密后SecretKey6BEC9C4B668B4B14B17EEF106BB98AE5Path请求接口路径/open-api/order/purchase-order-infoTimestamp请求时间戳(毫秒)1740709414000RandomKey5位随机字符串test1步骤2：组装签名数据(VALUE)将OpenKeyId、Timestamp和Path按特定格式拼接：OpenKeyId + "&" + Timestamp + "&" + Path示例结果：B96C15416C9240DF96BAA0BC9B367C6D&1740709414000&/open-api/order/purchase-order-info
步骤3：组装签名密钥(KEY)将SecretKey和RandomKey直接拼接：SecretKey + RandomKey示例结果：6BEC9C4B668B4B14B17EEF106BB98AE5test1步骤4：HMAC-SHA256加密并转十六进制使用步骤二得到的密钥(KEY)，对步骤一的数据(VALUE)进行HMAC-SHA256加密，然后将二进制结果转换为十六进制字符串：HexString = HMAC-SHA256(VALUE, KEY).toHexString()示例结果：d6ca2c789f5307de567f77717fcf098b114aeb415534166e61d0d192ba95acca步骤5：Base64编码对步骤三得到的十六进制字符串进行Base64编码：Base64String = Base64Encode(HexString)示例结果：ZDZjYTJjNzg5ZjUzMDdkZTU2N2Y3NzcxN2ZjZjA5OGIxMTRhZWI0MTU1MzQxNjZlNjFkMGQxOTJiYTk1YWNjYQ==步骤6：拼接RandomKey将RandomKey添加到Base64编码结果前面，形成最终签名：Signature = RandomKey + Base64String最终签名结果：test1ZDZjYTJjNzg5ZjUzMDdkZTU2N2Y3NzcxN2ZjZjA5OGIxMTRhZWI0MTU1MzQxNjZlNjFkMGQxOTJiYTk1YWNjYQ==

Q：咨询密钥什么情况下会失效？
2025-05-27
A：

密钥失效一般有以下几种情况：商家在后台取消授权，则密钥会立即失效，开发者将无法通过密钥调用接口。同时 SHEIN 开放平台会将密钥失效信息推送给开发者。 查看文档商家在商家后台点击重新授权，则商家会收到新的密钥短信，原先的密钥将失效。商家通过授权链接重新授权应用，完成授权后，旧的密钥将立即失效

Q：咨询密钥是否永久有效的？
2026-01-07
A：
正常情况下，密钥是永久有效的。可通过开发者控制台确认密钥的有效时间，路径： 登录开发者控制台 - 菜单“应用管理” - tab“授权记录” - 列表“授权有效期至”，若列表为空则代表永久有效

Q：子账号是否可以授权开发者应用？
2026-02-20
A：
由于店铺授权开发者应用后，应用可拉取店铺的数据，如商品、订单、库存等。因此，只有商家主账号可以完成应用授权。子账号无法授权应用。只有商家主账号可以完成应用授权。

Q：如何取消授权？
2025-10-27
A：
目前平台暂未提供取消授权的接口。若需进行取消授权操作，可以联系商家登录 SHEIN 商家后台，搜索并进入「第三方应用」页面。在页面中点击「我的授权」，即可查看所有已授权的应用列表。找到需要取消授权的应用后，点击“取消授权”按钮即可完成操作。

Q：supplierSource字段是指什么？
2025-12-04
A：
supplierSource为商家来源，是SHEIN内部定义的商家类型，用于确定唯一商家，开发者无需关注。
Q：如果一个商家有多个店铺，如何区分是哪个店铺？
2025-12-04
A：

当一个商家拥有多个店铺，并授权同一个开发者应用时，平台会为每个店铺生成唯一的密钥，其中 openkey 表示 SHEIN 平台上店铺与应用之间的唯一关系。如果你想知道每个 openkey 对应的商家信息，可以通过以下接口获取：
店铺信息查询接口： /open-api/openapi-business-backend/query-store-info
返回的数据包括：店铺名称（字段：storeName）店铺状态（字段：storeStatus）店铺商家ID（字段：supplierId）
注意：平台当前不提供查询应用授权记录的接口。如果开发者需要查看所有授权记录，可以登录 开发者后台 进行查询
