更新成本价
POST
/open-api/goods/update-cost
全托管
半托管
该API支持更新商品成本价（也称供货价）信息。

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
language
string	是	
默认返回中文多语言信息，支持语种：英语:en 法语: fr 西班牙语:es 德语:de 中文简体:zh-cn 泰语:th 巴西葡语:pt-br

Content-Type
string	是	
默认值：application/json

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId
x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000
x-lt-signature
string	是	
接口签名

请求参数（请求体）
收起
数据类型	是否必须	描述
skc_info_list
object[]	是	
skc信息。单次最多上传20个skc。

skc_name
string	是	
skc_name，skc_name是商品发布SHEIN生成的系统编码

change_price_reason_flag
string	是	
涨价原因code。需填写平台提供的枚举值，不可随意输入。

26年7月1日开始字段必填。不同商家可填写的涨价原因不同，需通过接口获取/open-api/goods/query-change-price-reason

change_remark
string	否	
涨价原因说明。商家可自定义输入内容，最多1000个字符。

file_upload_list
object[]	否	
涨价原因辅助材料，最多可上传1个材料。

object_key
string	是	
文件唯一编码。需通过接口转换获得：/open-api/goods/discuss/upload-discuss-file

type
string	是	
文件类型。1:图片（jpg / jpeg / png） 2:pdf 5:csv 6:excel（xls / xlsx）

必传，如果不传值可能会导致运营端无法正常查看材料，导致审核异常。

url
string	否	
文件地址。需通过接口转换获得：/open-api/goods/discuss/upload-discuss-file

sku_info_list
object[]	是	
sku信息。单次最多上传20个sku。

cost
double	是	
更新后的成本价（供货价）。

大于0小于100000的数值，最多2位小数点。



currency
string	是	
币种。需通过商品发布字段规范（含默认语种）获取，字段"currency"

sku_code
string	是	
sku_code，sku_code是商品发布SHEIN生成的系统编码

spu_name
string	是	
spu_name，spu_name是商品发布SHEIN生成的系统编码
