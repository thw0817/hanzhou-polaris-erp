请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
默认值：application/json

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId
x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000
x-lt-signature
string	是	
接口签名
x-lt-language
string	否	
指定出参语种，默认中文；支持语种:英语:US 法语:FR 西班牙语:ES 德语:DE 中文简体:CN 泰语:TH 巴西葡语:PT 土耳其语：TR

收起
数据类型	是否必须	描述
adminName
string	是	
用户名称（ERP系统可自行定义，用于系统记录此次发货的操作人，页面不展示）
agedProductCode
string	否	
时效产品编码，从物流产品查询接口获取
list
object[]	否	
skuCode
string	是	
sku编码，需要入参采购单中所有的SKU

orderNo
string	是	
订单编号

orderQuantity
integer	否	
下单数量

packageNum
integer	否	
包裹数（箱唛发货时必填，同一订单传相同包裹数）

tempDeliveryQuantity
integer	是	
实际发货数量：如果待发货数量大于500，单次发货需要大于150

packingInfoList
object	否	
装箱明细，当shippingRoute为1时需要传入装箱明细

packQuantity
integer	是	
装箱数量

skuCode
string	是	
装箱的sku编码

orderType
integer	是	
订单类型，1：急采，2：备货

deliveryType
integer	是	
发货方式，商家可用的发货方式枚举值请从发货基本信息查询获取；

arrivalTime
datetime	否	
预约SEHIN到仓时间（yyyy-MM-dd HH:mm:ss），当deliveryType=4或21时必填
shippingRoute
integer	否	
发货路径，0：无发货路径，1：直送路径，2：集货路径

expressId
string	否	
快递编码，SHEIN集成物流场景从物流产品查询接口companyCode字段获取，非SHIEN集成物流场景从发货基本信息查询接口companyCode获取，当deliveryType=1时必填

coding
string	否	
车队编码，当deliveryType=2且使用车队自送场景必填

expressInfo
object[]	是	
运单包裹信息

addrId
int64	是	
发货地址id，从发货基本信息查询接口中获取

expressCode
string	否	
快递单号，适用非SHIEN集成物流场景

packageNumber
integer	是	
总包裹数量（箱唛类型时=所有订单包裹的总计）

packageWeight
double	否	
包裹重量（单位:kg）

reserveParcelTime
datetime	否	
预约取货时间（yyyy-MM-dd HH:mm:ss），当使用SHEIN集成物流或SHEIN集成车队送货时必填

deliveryPackages
object	否	
包裹信息列表,包裹列表的长度必须与包裹数量相同
index
integer	是	
包裹序号，从0开始
packageHeight
double	否	
包裹高(cm)
packageLength
double	否	
包裹长(cm)
packageWeight
double	否	
包裹重量(kg)
packageWidth
double	否	
包裹宽(cm)
supplierWarehouseId
int64	是	
商家仓库id

subWarehouseId
integer	否	
供应商子仓ID
thirdPartyChannel
int64	否	
货代渠道

thirdPartyChannelName
string	否	
货代渠道名称

thirdPartyOrderMethod
integer	否	
货代下单方式：

1：SHEIN代下单

2：商家自行下单
