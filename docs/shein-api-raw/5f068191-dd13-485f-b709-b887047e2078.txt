FAQ
Q：发品成功后，是否支持修改销售属性和销售属性值？
2024-12-24
A：
不支持，商品一旦发品成功后，不允许修改属性和属性值；比如这个商品的销售属性是颜色，属性值是白色，一旦发品成功，编辑商品不再允许修改属性和属性值

Q：属性值多选如何传参？
2025-11-17
A：
属性的输入方式为多选（"attribute_mode": 1）时，每个属性值需要以独立一组数据的形式提供。例如"attribute_id": 101支持多选，若要选择两个属性值1000981、1000982，则需要按下方形式提供"product_attribute_list": [{
		"attribute_id": 101,
		"attribute_value_id": 1000981
	}, {
		"attribute_id": 101,
		"attribute_value_id": 1000982
	}, {
		"attribute_id": 333,
		"attribute_value_id": 493
	}, {
		"attribute_id": 160,
		"attribute_value_id": 1008347
	}, {
		"attribute_id": 60,
		"attribute_value_id": 459
	}]

2024-12-24
