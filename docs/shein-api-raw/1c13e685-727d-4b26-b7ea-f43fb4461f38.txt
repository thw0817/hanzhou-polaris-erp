全托管/SHEIN自营商家库存更新
POST
/open-api/goods/stock-update
全托管
SHEIN自营
POP
该API用于更新代运营（又称全托管、简易平台）和SHEIN自营商家的库存，接口支持全量方式更新；

⚠️注意：自主运营和半托管模式应用请勿使用；
