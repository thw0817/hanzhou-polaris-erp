获取议价单列表
POST
/open-api/goods/discuss/query-discuss-list
全托管
半托管
支持获取商品成本价的议价单列表。

目前仅支持3种议价类型：新品议价、老品议价、新品核价复议

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
application/json

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId

x-lt-signature
string	是	
请求签名

x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：158339876400

language
string	是	
语种。默认为中文。支持语种:英语:US 法语:FR 西班牙语:ES 德语:DE 中文简体:CN 泰语:TH 巴西葡语:PT 土耳其语：TR

请求参数（请求体）
收起
参数名称	数据类型	是否必须	描述
discussStatus
integer	否	
议价单状态,。

1:待商家确认 2:待平台审核 3:接受议价 4:不接受议价 5:议价终止-成功 6:议价终止-失败

pageNum
integer	是	
分页数量。建议从1开始查询

pageSize
integer	是	
分页内条数，单页最多200

返回参数（响应体）
收起
数据类型	是否必须	描述
code
string	否	
响应码

info
object	是	
响应详情

count
integer	否	
查询结果条数

data
object[]	是	
具体数据。目前仅支持3种议价类型：新品议价、老品议价、新品核价复议

allPicUrls
string[]	否	
SKC的所有商品图片

appealCount
integer	否	
议价单剩余可议价次数。（平台不允许对同一个SKC进行无限次议价行为，因此会有次数限制，当剩余次数为0时，议价单状态变为6终止-失败）

appealReason
string	否	
建议改价原因（平台侧写入的内容）

discussSn
string	否	
议价单单号

discussStatus
integer	否	
议价单状态。

1:待商家确认 2:待平台审核 3:接受议价 4:不接受议价 5:议价终止-成功 6:议价终止-失败

discussType
integer	否	
议价单类型。

0:新品议价 1:老品议价 3:新品核价复议

fileUploadList
object[]	是	
议价上传的辅助材料

file_name
string	否	
原始文件名

object_key
string	否	
文件唯一key，需通过接口/open-api/goods/discuss/upload-discuss-file上传文件后获取

type
integer	否	
文件类型 1:图片

url
string	否	
文件url，需通过接口/open-api/goods/discuss/upload-discuss-file上传文件后获取

isSizeSamePrice
integer	否	
是否限制所有尺码同价

1-是（代表SKC下所有SKU的价格需相同，即议价时也需要相同）；0 否

mainPicUrl
string	否	
商品主图地址
productTitle
string	否	
商品标题

reason
string	否	
议价原因（商家侧输入的内容）

saleAttributeValue
string	否	
SKC销售属性值

serialNumber
integer	否	
当前议价的轮次数

skcName
string	否	
平台的skc编码

skuCostPrices
object[]	是	
sku成本价列表

costPriceHistories
object[]	是	
商家的成本价报价记录

costPrice
double	否	
成本价

currency
string	否	
币种
serialNumber
integer	否	
报价轮次数

latestCostPrice
double	否	
最近一次的商家报价价格。如果serialNumber=1即商家侧还没有发起过报价时，则此字段无数据。

saleAttributeValues
string[]	否	
次规格属性值

skuCode
string	否	
平台的sku编码

suggestCostCurrency
string	否	
平台的建议成本价币种

suggestCostPrice
double	否	
平台的建议成本价
spuName
string	否	
平台的spu编码

supplierCode
string	否	
商家的skc货号

msg
string	否	
响应信息

收起
请求示例
复制
curl --location --request POST 'http://openapi-test01.sheincorp.cn/open-api/goods/discuss/query-discuss-list' \
--header 'x-lt-signature: test' \
--header 'x-lt-openKeyId: test' \
--header 'x-lt-timestamp: 1762494208230' \
--header 'language: US' \
--header 'Content-Type: application/json' \
--header 'Host: openapi-test01.sheincorp.cn' \
--data-raw '{
  "discussStatus":"",
  "pageNum":1,
  "pageSize":10
}'
