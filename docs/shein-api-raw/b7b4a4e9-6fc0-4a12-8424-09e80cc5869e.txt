查询商品可退库存数
POST
/open-api/purchase/returnable-inventory
全托管
查询指定商品在仓库中可退货或报废的库存数量

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId
x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000
x-lt-signature
string	是	
接口签名
请求参数（请求体）
收起
参数名称	数据类型	是否必须	描述
applyType
integer	是	
申请类型：1=退货 2=报废
queryType
integer	是	
发起维度：1=SKC；2=采购单号(开发者可忽略)；3=平台SKU

sellerOrderNos
string[]	否	
采购单号列表，queryType=2时必传，最多50个；开发者可忽略，API暂不支持通过采购单发起

skcNames
string[]	否	
SKC列表，发起维度=SKC时必传，最多50个

skuCodes
string[]	否	
平台SKU列表，发起维度=平台SKU时必传，最多50个
