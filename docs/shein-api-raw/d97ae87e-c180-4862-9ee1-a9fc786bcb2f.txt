查询商品删除审核记录
POST
/open-api/goods-delete-logs/search
自运营
全托管
半托管
可查询近一年内，商家发起的商品删除的申请审核记录（平台发起的删除不在此范围内，平台会定期对长期无动销的商品进行删除）

入参查询status_list=2（审核成功）的话，可获取到已删除的SKC列表。

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
默认值：application/json

x-lt-openKeyId
int64	是	
访问用户隐私数据时的唯一权限标识 openKeyId

x-lt-timestamp
integer	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000

x-lt-signature
string	否	
接口签名

language
string	否	
支持返回的多语言报错信息，例如：language:en。默认返回中文多语言信息 英语:en 法语: fr 西班牙语:es 德语:de 中文简体:zh-cn 泰语:th 巴西葡语:pt-br

请求参数（查询参数）
收起
参数名称	数据类型	是否必须	描述
page_num
integer	是	
页码，从1开始
page_size
integer	是	
每页条数，最大100

请求参数（请求体）
收起
参数名称	数据类型	是否必须	描述
apply_no_list
string[]	否	
申请单号列表，单次最多10个。

skc_name_list
string[]	否	
SKC平台编码列表，单次最多10个。

skc_supplier_code_list
string[]	否	
SKC商家货号列表，单次最多10个。

status_list
integer[]	否	
删除申请的审核状态列表：0-待审核 1-审核中 2-成功 3-失败

submit_time_end
datetime	否	
申请提交时间段，结束时间（东八区），格式：yyyy-MM-dd HH:mm:ss。

最多可查询近一年的审核记录

submit_time_start
datetime	否	
申请提交时间段，开始时间（东八区），格式：yyyy-MM-dd HH:mm:ss。

最多可查询近一年的审核记录
