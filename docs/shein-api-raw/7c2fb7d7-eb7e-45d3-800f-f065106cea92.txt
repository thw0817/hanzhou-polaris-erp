查询退货与报废单列表
POST
/open-api/purchase/return-list
全托管
分页查询退货单、报废单列表数据；如何对接请查看采购单退货解决方案

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
application/json

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId

x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000

string	是

string[]	否	
退货单号列表（最多200个），有值时，startTime/endTime/queryType可不传

integer[]	否
