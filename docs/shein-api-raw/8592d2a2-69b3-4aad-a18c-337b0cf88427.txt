查询代理公司列表
POST
/open-api/goods-compliance/agency-list
自运营
全托管
半托管
POP
查询商家申报的代理公司信息，包括欧盟责任人、制造商、美国代理、英国代理，此接口的返回信息在SKC绑定代理公司时会使用。

代理公司的整体解决方案，可点击查看文档。

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
application/json

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId

x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：158339876400

x-lt-signature
string	是	
查看签名生成规则

language
string	否	
指定出参语种，默认中文；支持语种:英语:EN 法语:FR 西班牙语:ES 德语:DE 中文简体:CN 泰语:TH 巴西葡语:PT 土耳其语：TR

收起

agencyId

代理公司ID
agencyName
string	否	
代理公司名称（精确匹配，不支持模糊匹配）
pageNum
integer	是	
页码，从1开始

pageSize
integer	是	
每页大小，最多100

agencyProvinceName
string	否

string	否	
代理期限开始时间

integer	否	
代理公司状态，基于代理期限时间生成的状态。0-生效中，1-已过期，2-未生效。

agencyStatus=0，且applyStatus=1/2的代理公司才可以和SKC绑定。

agencySubType
integer	否	
代理公司的二级类型。只有0-欧盟责任人有二级类型：20-欧洲代理；21-欧盟制造商；22-欧盟进口商；23-欧盟配送服务提供商

agencyType
integer	否	
代理公司的一级类型。0-欧盟责任人；1-英国代理；2-美国代理；3-制造商

applyStatus
integer	否	
代理申报的审核状态。0-待补充；1-待审核（商家后台页面会展示申报成功，接口层可认为此状态的代理公司可以和SKC绑定）；2-申报成功；3-审核失败；

agencyStatus=1，且applyStatus=1/2的代理公司才可以和SKC绑定。

areaCode
string	否	
联系电话区号

brandCodes
string[]	否	
品牌编码列表
contactName
string	否	
联系人姓名
coveredProductRange
integer	否	
代理公司覆盖的商品范围。1-全部商品；2-部分商品；

覆盖范围是1-全部商品时，SKC生成后将自动和代理公司完成绑定，不需要手动绑定。

createTime
datetime	否	
代理公司的创建时间
email
string	否	
电子邮箱
originType

来源类型：0-手动创建，1-线上办理

邮政编码
supplierId

telephone

title
string	否	
责任人/公司名称

datetime	否	
代理公司信息的更新时间

string	否	
追踪码
