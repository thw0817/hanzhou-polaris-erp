商品发布字段规范
POST
/open-api/goods/query-publish-fill-in-standard
自运营
全托管
半托管
每个店铺在各个分类下有不同的商品发布字段填写规范（要求）。建议在调用商品发布接口前，先调用此接口。本接口可查询的要求范围包括：

1、商品标题和商品描述的必填默认语种（default_language）

2、商品发布时是否必传竞品链接和库存证明（reference_product_link和proof_of_stock）

3、商品发布时是否必传样品信息（sample_info）

4、商品发布时是否必传品牌（brand_code）

5、商品发布时是否必传skc标题（skc_title）

6、半托管和全托管的供货价币种（currency）

7、商品是否支持sku和spu维度的图片（picture_config_list）

8、商品发布时是否必传最小备货数量（minimum_stock_quantity）

9、商品是否支持上传详情图（product_detail_picture）

10、商品是否支持在SKU维度传件数（quantity_info)

11、商品是否支持传SKC建议零售价（suggest_price）

12、商品是否支持填写商家条码（supplier_barcode）

13、商品是否支持填写SKU包装类型（package_type）

14、商品是否支持上传IP信息（ip_character）

FAQ
Q：半托管的商品币种如何获取？
2025-05-26
A：
店铺可用币种需要通过接口获取：/open-api/goods/query-publish-fill-in-standard；返回参数中的“currency”代表供货价币种，即半托管和代运营业务货币种类。

Q：商品发布报错"样品信息不能为空"，ERP如何知道这个字段是否必填？
2024-12-24
A：
可调用商品发布规范确认店铺是否需要上传样品信息接口地址： https://open.sheincorp.com/documents/apidoc/detail/3000293-1000001
Q：Item title cannot be empty这个报错是什么原因？
2025-10-23
A：

报错 “Item title cannot be empty” 表示在调用商品上传接口时出现以下问题之一：未上传商品标题字段：即 multi_language_name_list -> name 字段为空或未提供。未上传店铺默认语种的标题：即 multi_language_name_list -> language 中未包含店铺的默认语种。每个店铺都有其默认语种，商家在设置商品标题和名称时，必须提供该默认语种的商品标题（name）和语言标识（language）。
如未设置，系统会返回该报错
如何查询店铺默认语种？如需查询店铺默认语种，可调用以下接口：/open-api/goods/query-publish-fill-in-standard，接口地址： https://open.sheincorp.com/documents/apidoc/detail/3000293-1000001
请确保在商品上传请求中满足以下要求：multi_language_name_list -> language 字段中包含店铺默认语种；multi_language_name_list -> name 字段中有对应的商品标题
