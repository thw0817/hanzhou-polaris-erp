spu商品详情查询
POST
/open-api/goods/spu-info
自运营
全托管
半托管
POP
支持通过SPU查询商品信息。只有发布且已通过平台审核的SPU才能查到信息。

可查信息：SPU/SKC/SKU维度品牌、名称、图片、属性、上架状态、价格、样品信息。

不可查询信息：商品库存、属性排序。

string	是

string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000

收起
参数名称	数据类型	是否必须	描述
languageList
string[]	是	
语种列表。指的是商品名称、商品描述、属性名称会返回哪些语种信息。建议入参商家的默认语种，确保能拿到有效数据，默认语种通过商品发布规范获取。

最多可给5个语种，支持语种包括：英语:en、法语:fr、西班牙语:es、德语:de、中文简体:zh-cn、泰语:th、巴西葡语:pt-br、日语:ja、韩语:ko

Q：什么是product_id和goods_id？SHEIN平台商品唯一标识是什么？
2025-11-12
A：

SHEIN平台没有叫做product_id的标识。常见的商品唯一标识有：SPU（字段：spu_name）：平台生成的SPU唯一编码，代表一个商品型号或款式，包含多种颜色、尺码等变体。SPU标识用于接口查询商品信息。SKC（字段：skc_name）：平台生成的SKC唯一编码，在SPU基础上增加了主销售属性（通常为颜色）。SHEIN的商品层级关系有3层，其中SKC是销售属性，也叫主规格属性，例如一个商品有黑色和白色两种颜色，黑色和白色会分别生成skc_name；SKC标识一般用于接口修改商品上下架。SKU（字段：sku_code）：平台生成的SKU唯一编码，是最小产品单元，区分每个具体规格，如款式、颜色、尺寸。SKU是最小的产品单元，但也是销售属性，也叫次规格属性，比如黑色有S、M、L三个尺码，S、M、L三个尺码分别对应不同sku_code；SKU标识一般用于接口修改库存和价格。
商品标识可通过商品列表接口获取：/open-api/openapi-business-backend/product/query。⚠️注意：商品列表接口只返回审核通过的商品信息。平台未提供接口获取审核中或审核失败的商品标识。开发者使用商品发布接口 /open-api/goods/product/publishOrEdit 上传商品后，接口会返回spu_name、skc_name、sku_code参数，但此时商品处于审核中或可能审核失败，因此不会通过商品列表接口返回。商品标识之间的关系（spu、skc、sku）可通过商品详情接口获取：/open-api/goods/spu-info
SHEIN平台也没有goods_id的标识。但是有订单详情接口有goodsid字段；接口：/open-api/order/order-detail订单详情里面的商品数量可以根据goodsid来统计，每件商品的唯一ID。如果一个 SKU 有多件，每一件的goodsId都是唯一的

Q：spu维度的supplier_code和skc维度的supplier_code怎么传值？
2024-12-10
A：
SHEIN货号管理是到skc维度，店铺维护货号支持spu维度维或skc维度维护两种模式：若店铺支持spu维度，则取用户填写的spu维度的supplier_code，作为skc的supplier_code，并忽略用户填写的skc维度supplier_code；若店铺支持skc维度，则取用户填写的skc维度的supplier_code，作为skc的supplier_code，并忽略用户填写的spu维度supplier_code；目前没有规则透传出哪个需要传，因此发布商品两个都需要传，需要注意的是通过spu商品详情查询（新）API获取到的spu维度的supplier_code、skc维度的supplier_code会和发布商品入参存在不一致的情况；
