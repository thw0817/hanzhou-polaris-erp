查询资质证书填写规则
POST
/open-api/goods-certificate-schemas/detail
自运营
全托管
半托管
POP
获取资质证书的填写规则，仅支持获取complianceGroupCode=ZSZZL的规则，其他合规信息的填写规则请通过其他接口获取。

完整的资质证书接口调用方案，详见文档

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
默认值：application/json
x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId
x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000
x-lt-signature
string	是	
接口签名
language
string	否	
响应msg的语种。不传时默认为中文，枚举值支持语种:英语:US 法语:FR 西班牙语:ES 德语:DE 中文简体:CN 泰语:TH 巴西葡语:PT 土耳其语：TR

请求参数（请求体）
收起
参数名称	数据类型	是否必须	描述
certificateTypeCodes
string[]	否	
证书类型code，单次最多查询10个。

certificateTypeIdList
int64[]	否	
证书类型id,批量查询数量最多:1000

返回参数（响应体）
收起
数据类型	是否必须	描述
code

string	否

响应信息

object[]	否	
证书类型信息列表

certificateDimension
integer	否	
证书绑定维度：1:部分商品（需手动和SKC绑定）；2:全部商品

certificateLabel
string	否	
证书类型标识：0普通类型；1自符类型；2-溯源证书。

目前API仅支持0普通类型的资质证书创建。

certificateType
string	否	
证书类型值描述

certificateTypeId
int64	否	
证书类型id

complianceGroupCode
string	否	
合规信息分组code。枚举值：HGXXL-合规信息类；SPTL-卖点类；GSL-公司类；ZSZZL-证书资质类；SPSMS-说明书

【重要】此接口只能获取ZSZZL的填写规则，其他分组的填写规则需要通过其他接口获取。
