/open-api/stock/stock-query
自运营
全托管
SHEIN自营

POP
支持通过sku、skc、spu查询库存数量

请求参数：请注意，skuCodeList/skcNameList/spuNameList三个参数不能全部为空，至少传入一个

invType为新增参数，用于更准确地表达库存类型。原warehouseType参数将于2026年12月31日废弃下线，建议尽快切换至invType。过渡期内两个参数可同时使用，当同时传入时以invType为准。

FAQ
Q：如何监控库存水平，避免库存过剩或不足？
2025-05-26
A：
可以有两种方式来实现库存预警功能：ERP 根据订单和商品库存查询库存情况，并更新信息，从而开发库存预警功能，以确保在库存紧张或过剩时及时通知商家。ERP 接入平台提供的预警提醒功能。该平台支持库存预警的 webhook，旨在帮助商家更好地管理库存，确保商家及时了解到即将售罄的 SKU。ERP 通过接入 webhook，可以帮助商家做好 SKU 库存预警，通知路径为：/inventory_warning_notice。

Q：库存不足的情况下，系统会如何处理订单？
2025-05-26
A：
库存不足后，消费者在前端将看到商品售罄的提醒，需商家及时补充库存。
Q：如何确认商品是否在同一个仓库中？
2025-05-26
A：
ERP 可以使用库存查询接口 “/open-api/stock/stock-query” 确认商品是否在一个仓库中。
Q：ERP 是否可以通过接口控制库存锁定？
2025-05-26
A：
由于正式锁和临时锁都是消费者行为，无法通过 API 修改临时锁或者正式锁占用的库存。
Q：什么是锁定库存和临时锁库存？咨询锁定库存何时会释放？有哪些场景？
2025-05-26
A：
平台定义的正式锁指的是消费者付款的订单占用的库存，会在发货后释放。平台定义的临时锁指的是消费者下单未付款的订单占用的库存，订单取消或者转成付款都会释放临时锁库存。订单取消后会将库存更新为店铺可用库存，付款后会将临时锁库存变更为正式锁库存。

Q：商家自履约和SHEIN履约在什么时候会扣减总库存
2024-12-24
A：
1、商家自履约在导出地址的时候会扣减库存；2、shein履约（非巴西市场）是打印面单的时候会扣减库存；3、shein履约（巴西市场）是导出地址的时候会扣减库存；

Q：/open-api/stock/stock-query接口会返回卖家sku编码（supplierSku）吗
2025-11-10
A：
不会，/open-api/stock/stock-query接口会返回shein生成的skuCode，但不会直接返回卖家自己维护的sku编码（supplierSku）。如果您想要获取某个卖家sku编码对应的库存，需要先通过调用/open-api/goods/spu-info获得shein sku编码（skuCode）和卖家sku编码（supplierSku）之间的映射关系。
