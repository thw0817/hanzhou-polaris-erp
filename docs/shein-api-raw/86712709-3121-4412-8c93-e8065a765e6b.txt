查询商家退货地址
POST
/open-api/purchase/query-return-address
全托管
获取商家可用的退货收货地址列表

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId
x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000
x-lt-signature
string	是	
接口签名
请求参数（请求体）
收起
参数名称	数据类型	是否必须	描述
addressIdList
integer[]	否	
卖家地址唯一ID集合,如果入参此ID 列表不为空，只会返回此ID列表中所有 id 对应的地址明细
filterSharedAddress
boolean	否	
是否过滤共享地址 true:过滤 false:不过滤(默认不过滤)；开发者可忽略

fuzzyQuery
string	否	
模糊搜索,地址简称、手机区号和联系人的全模糊搜索

orderBySharedAddress
boolean	否	
是否按商群共享地址排序，当入参该值并且是true时，会把共享地址排在前面,如果不传按默认排序；开发者可忽略

pageNum
integer	否	
页码,默认第一页

pageSize
integer	否	
每页条数,默认10条

serviceSiteCodeList
string[]	否	
VSS增值系统提供的服务点ID集合,1、VSS增值系统提供的服务点ID 2、如果入参此ID，只会返回此ID对应的地址明细（不区分服务点启用or禁用状态）；开发者可忽略
