查询资质证书列表
POST
/open-api/goods-certificates/search
自运营
全托管
半托管
POP
获取店铺内已经创建好的资质证书列表（对应商家后台-合规-商品合规管理-证书库tab列表）。

完整的资质证书场景接口调用方式，详见文档

请求参数（请求头）
收起
参数名称	数据类型	是否必须	描述
Content-Type
string	是	
默认值：application/json

x-lt-openKeyId
string	是	
访问用户隐私数据时的唯一权限标识 openKeyId

x-lt-timestamp
string	是	
请求时间戳，格式为时间转换为毫秒的值，也就是从1970年1月1日起至今的时间转换为毫秒，如：1583398764000

x-lt-signature
string	是	
接口签名

language
string	否	
响应msg的语种。不传时默认为中文，枚举值支持语种:英语:US 法语:FR 西班牙语:ES 德语:DE 中文简体:CN 泰语:TH 巴西葡语:PT 土耳其语：TR

请求参数（请求体）
收起
参数名称	数据类型	是否必须	描述
certificateTypeCodeList
string[]	否	
证书类型编码列表，单次最多查询10个。

fileName
string	否	
证书文件名称（即证书中图片或pdf文件的名称），模糊查询

pageNum
integer	是	
页码，从1开始

pageSize
integer	是	
每页大小，最大100。

poolSnList
string[]	否	
证书编号列表（即平台对每份证书的唯一编码）

statusList
integer[]	否	
证书状态列表：1-待生效，2-已生效，3-已失效，4-待填写，5-即将失效，6-草稿。

返回参数（响应体）
收起
数据类型	是否必须	描述
code
string	是	
响应编码 成功：0

msg
string	否	
错误描述,成功：OK
info
object	否	
响应信息

data
object[]	否	
列表数据

alertTime
datetime	否	
证书预警日期

bindSkcFlag
integer	否	
是否已绑定SKC：1-是，0-否

certificateDimension
integer	否	
适用范围维度：1-部分商品，2-全部商品

certificateTypeCode
string	否	
证书类型编码

certificateTypeId
int64	否	
证书类型ID

certificateTypeName
string	否	
证书类型名称

effectiveTime
datetime	否	
证书生效日期

fileList
object[]	否	
证书中包含的文件列表

fileGroup
integer	否	
文件分组：0-默认值，1-本体，2-包装，41-PDF简版文件，42-PDF完整版文件。

fileMd5
string	否	
文件MD5

fileName
string	否	
文件名称

fileUrl
string	否	
文件URL

insertTime
datetime	否	
新增时间

langs
string[]	否	
文件语种列表

insertTime
datetime	否	
记录插入时间

invalidTime
datetime	否	
证书失效日期
lastUpdateTime
datetime	否	
证书信息更新时间

poolId
int64	否	
证书ID。此字段使用场景较少，更多使用的是poolSn。

poolSn
string	否	
证书编号。更多接口里使用的证书唯一编码是这个字段。

presetInfoList
object[]	否	
证书中的字段信息列表。

presetId
int64	否	
字段ID

valueList
object[]	否	
字段值列表

value
string	否	
字段值。覆盖两种情况。

1、检验机构字段（归属于otherPresetInfoList且sourceFrom=SRM），此处是实验室id（srmDetectionAgencyList-laboratoryId）

2、非检测结构字段（归属于presetInfoList，inputType=3/4，如生效时间），此处是手动输入值

valueId
int64	否	
字段值ID。覆盖两种情况。

1、检验机构字段（归属于otherPresetInfoList且sourceFrom=SRM），此处是检测结构id（srmDetectionAgencyList-detectionAgencyId）

2、非检测结构的字段（归属于presetInfoList，inputType=1/2），此处是所选id（presetInfoList-presetValueList-presetValueId）

status
integer	否	
证书状态：1-待生效，2-已生效，3-已失效，4-待填写，5-即将失效，6-草稿

supplierId
int64	否	
商家ID

meta
object	否	
元数据

count
integer	否	
数据记录数

customObj
object	否	
用户自定义扩展
traceId
string	否	
追踪码
