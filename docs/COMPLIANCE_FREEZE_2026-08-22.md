## 已冻结的业务边界

- 商品本体实拍图与商品包装实拍图严格分组，分别进入 `bodyLableList` 与 `packageLableList`，不使用已废弃的 `skcLablePicList`。
- 商品本体实拍图不是建品阶段必传项；只有 SHEIN 对当前 SKC 明确返回必传且失败/待补充时，才允许进入当前 SKC 的真实提交。
- 商品包装实拍图支持多张；真实提交只发送当前必传且失败/待补充的分组。非必传历史失败不能升级为当前阻断，旧失败原因只在当前必传失败时保留。
- 1630/1631 由当前商品级官方属性重新判定：面积大于 2.16m² 或最长边大于 1.8m 任一为“是”时为 1630，两项均为“否”时为 1631；缺项、未知值或来源不可信时失败关闭。
- 官方英文别名固定为 `SmallCarpet → 1631`、`LargeCarpet → 1630`；包含明确 `1630/1631` 数字时以明确数字为准。
- 1630 与 1631 使用独立报告模板。模板包含自定义名称、报告类型、报告文件和报告日期；引用后日期随模板继承，但每个 SKC 仍独立上传、创建证书和绑定，不能复用旧 `poolSn`。
- 实拍图和报告真实提交都要求当前有效规则、当前店铺受保护媒体、单 SKC 载荷、短期确认令牌和写后只读回读；顶层成功但内部部分失败仍按失败处理。
- 店铺制造商、欧盟/土耳其责任人等已通过项目默认隐藏；单 SKC 页面默认优先展示用户真正需要处理的项目。
- GCC、产品标识符及其他官方未开放写接口的字段保持只读，不能伪造提交能力。

## SHEIN 官方能力限制（不是本系统缺陷）

- 当前实拍图查询接口不返回平台历史图片原图、可删除图片 ID 或删除接口。
- 再次绑定新图不等于官方承诺删除或覆盖历史图，界面和服务端不得作出覆盖保证。
- SHEIN 接收提交不等于审核通过；最终状态必须以后续官方只读回读为准。
