# NEXUS-EVO-09：统一 UI、性能与可观测性验收

日期：2026-08-26

## 验收结论

- 运营页面继续使用统一的 Operations primitives、TanStack Table/Virtual 和 Radix/Tailwind 交互基础，不引入第二套后台 UI 框架。
- 列表在 100 行以内保留原生表格几何，超过 100 行才启用 TanStack Virtual，避免小数据表格出现错位；合规、审核和批量建品均保留横向滚动与紧凑列宽。
- 所有核心页面保留加载、空数据、错误、缓存过期、权限和手动刷新状态；页面切换不因窗口焦点或重挂载自动读取 SHEIN。
- 图片使用稳定同源媒体 URL、私有长期缓存和懒加载；不可用图片有明确占位，不阻塞整页。
- 查询缓存默认有界回收、关闭 reconnect/focus 风暴，失败只做一次有限 5xx 重试；写操作不自动重试。
- 发布、合规、草稿和批量建品统一显示操作反馈，危险操作保留可追踪结果；V2 路由采用懒加载，供应商依赖进入可缓存 vendor chunks。
- HEF/HST/HWF/SRF 的租户、用户、店铺作用域合同仍保持有效，未发现跨店铺缓存或后台轮询回归。

## 回归验证

- V2 核心 UI、权限、缓存、图片、发布、合规、草稿、批量建品和总览专项：`85/85` 通过。

本阶段未引入新的 UI 框架或全局重绘；全量测试、V2 构建、发布审计和云端部署统一留到 NEXUS-EVO-10。
