# PostgreSQL Runtime Role 人工验收记录模板

本模板用于维护窗口中的人工记录。先复制到受控变更系统再填写；填写后的记录不得提交到代码仓库。

不得粘贴数据库 URL、密码、私钥、访问令牌或完整 `.env`。不得记录可执行的权限变更语句、ACL 明细、
角色成员清单或数据库查询结果行。只记录逻辑标识、仓库静态检查名、审批结论和受控附件编号。
